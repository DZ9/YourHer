# Roadmap

The initial public edition includes the complete companion web workflow, a standalone memory engine, shared conversation/chips behavior, injected UI components, provider and storage boundaries, weekly letters/moods, and configurable localization.

Next priorities:

1. Verify selected real model providers and record model/configuration versions, latency and API usage.
2. Add a transactional database adapter for multi-process deployments.
3. Evaluate memory extraction, corrections, stale facts and deletion using synthetic multi-session data and transparent baselines.
4. Add email verification/password recovery or an optional external authentication adapter.
5. Add community translations and validate RTL layouts with native-language reviewers.
6. Expand documented examples of using packages without the web host.

Do not claim reinforcement-learning results, semantic-memory conflict resolution, provider compatibility or production-scale reliability without corresponding implementation and evidence.
