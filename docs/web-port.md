# 小程序 → 完整网页产品迁移清单

原产品：个人私有 chatNPC（此刻）`apps/miniapp_v2`。原生产仓库仍保留私有，不发布历史和生产配置。

| 原产品入口/链路 | 网页版对应 | 实现与验收 |
|---|---|---|
| 唯一主入口 chat | 聊天页 `#/chat` | 原立绘、暖色/夜间紫金、首触文案、同意隐私、陪伴者选择 |
| 流式多气泡 | 服务端 SSE + 浏览器多气泡 | 空行分段，角色、时间、AI 标识、重用消息、浏览器朗读 |
| A1 回复 chips | 原 candidates 模块 + 流式缓冲 | 兼容 0–2 个下划线；不显示部分 marker；保存 rawContent 与解析结果 |
| A2 新用户 chips | 原统一文案中的三条引导 | 点击直接发送；输入、生成、录音时隐藏 |
| A5 回访 chips/opener | 原 returning 模块 | 30 分钟/24 小时分档，承接上次话题，复用末次候选 |
| 对话历史/恢复 | 服务端落库 + 幂等 requestId + 轮询恢复 | 断开浏览器不取消已开始的模型回复；刷新读取完整记录；加载更早历史 |
| 记忆确认条/撤销 | 聊天顶部 banner | 新记忆才提示，可立即忘记 |
| 聊天命名与撤销 | 模型分析 → profileUpdate → banner | 自报姓名/AI 起名同步关于页与顶栏，可撤销 |
| 右上四面板 | 原版右上纵向导航、滑入面板 | 信、记得、心情、关于；保持聊天状态；桌面保留原应用窄屏比例 |
| 信与历史信 | `#/letters` | 每周保存一封，至少三条用户消息；手动触发/可选周日调度 |
| 她记得/他记得 | `#/memory` | 类型、内容、时间、删除；与独立记忆包共用实现 |
| 心情月历/每日打卡 | `#/mood` + 每日浮层 | 月份切换、当天补打/修改；明确手动打卡优先于对话推断 |
| 关于/个人资料 | `#/about` + 编辑弹窗 | 同行天数、完整计数、AI 名字/性别、昵称、城市、语气、关系、日夜模式 |
| 问题反馈 | `#/feedback` | 类型、内容、截图上传、保存到当前实例 |
| 体验问卷 | `#/survey` | 三问、持久化、重复提交防护；自托管版不伪造奖励 |
| 会员/付费墙 | `#/membership` | 改为自托管无限制说明，不携带原商户/微信虚拟支付，不假收款 |
| 微信身份/手机号 | 网页账户与访客会话 | 访客自动会话；邮箱密码注册/登录、保留访客数据、退出；没有邮件验证/找回密码服务 |
| 隐私/账户数据 | `#/privacy`、`#/security` | 独立自托管隐私说明、导出、确认后删除账户及数据 |
| 微信语音输入/输出 | 浏览器语音适配 | 支持时由用户发起识别/朗读；不支持时明确提示；没有接入微信语音服务 |
| 云端监控/运营后台 | 不复制生产系统 | 不携带真实埋点、云监控、管理账号、运营文章或线上数据 |

页面是可操作的真实网页流程，不是截图拼接。实际模型效果仍取决于所配置的模型。离线模式全部明确标为规则演示，不把固定话术当模型结果。

原 `home`、旧 `me`/`records` 的冗余二级页在小程序中已退役；网页保持聊天核心结构，旧 hash `#/me`/`#/records` 分别映射到关于/信。
